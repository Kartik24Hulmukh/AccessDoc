AccessDoc Evidence API

Two POST endpoints, one JSON contract, no state kept. Machine-readable spec: /openapi.json (OpenAPI 3.1). Ceilings: /limits. Readiness: /readyz.

Body limit 2 MiBreport.html is the accessible primary artifactreport.pdf is untagged convenienceEvery response has X-Request-ID

1. Generate an evidence bundle

POST axe-core JSON as scanner_input. You receive application/zip containing report.html, report.pdf, receipt.json (schema 1.2), openacr.yaml, attestation.intoto.json and manifest.json (SHA-256 of every member).

curl -sS https://access-doc.vercel.app/api/bundle \
  -H 'Content-Type: application/json' \
  -d '{"scanner_input": {"violations": []}, "client_name": "Example", "agency_name": "Studio", "audit_date": "2026-09-16"}' \
  -o bundle.zip && unzip -l bundle.zip

With a real scan: npx axe https://example.com --save axe.json then -d "$(jq -c '{scanner_input: .[0], client_name: "Example"}' axe.json)".

2. Remediation plan (advisory)

curl -sS https://access-doc.vercel.app/api/remediate \
  -H 'Content-Type: application/json' \
  -d '{"violations": [{"id": "color-contrast", "impact": "serious", "nodes": [{"html": "<p>low contrast</p>"}]}]}'

If no model is reachable the response is still 200, with degraded: true and header X-AccessDoc-Mode: degraded-offline-kb: deterministic WCAG 2.2 guidance from the offline knowledge base, zero hallucinated tokens.

3. Error contract

Every error is JSON {"error": "...", "request_id": "..."}. 400 malformed JSON · 401 unauthorized (auth-gated deployments only) · 405 wrong method · 411 Content-Length required · 413 over 2 MiB or over /limits · 415 wrong Content-Type · 422 invalid axe structure · 503 capacity exhausted (honour Retry-After).

4. Verify a bundle offline

python3 scripts/verify_bundle.py bundle.zip   # manifest SHA-256 + receipt schema 1.2

Receipts are frozen provenance: finding_fingerprint_version, per-finding fingerprints, axe-core version and coverage note survive model churn.

What this API does not do

No certification

AccessDoc organises supplied evidence. It does not establish WCAG, ADA, EAA, or legal compliance.

No scanning

Bring your own axe-core results; automated checks detect only part of WCAG.

No retention

The bundle endpoint keeps nothing after the response is written.
